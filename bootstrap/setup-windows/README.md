# Setup Windows

This setup uses PowerShell for Windows tools and WSL for Linux tools. Keep the two environments separate and clone this repo into both.

## PowerShell

Follow [PowerShell setup](powershell.md) for Windows package managers, PowerShell 7, CLI tools, and the profile.

## WSL

Follow [WSL setup](wsl.md) for Ubuntu, zsh, Homebrew, and Linux CLI tools.

## Start here

1. Set up Windows tools with the PowerShell guide.
2. Install Ubuntu and configure WSL with the WSL guide.
3. Follow the root README to create the dotfile symlinks in each environment.
